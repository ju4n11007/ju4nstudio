¿Qué es Arduino?

Arduino es un sistema que combina una placa electrónica y un software gratuito que se instala en tu computador.

El software sirve para darle instrucciones a la placa. Escribes órdenes sencillas (como "enciende esta luz" o "mide la temperatura") y el software las convierte en señales que la placa entiende y ejecuta.

💡 Ejemplo: Puedes programar un sensor de luz para que encienda un LED automáticamente cuando oscurezca. El software es el que traduce tus ideas a órdenes que la placa obedece.

🧠 Lo estoy aprendiendo para poder ofrecer soluciones que mezclen el mundo digital (páginas web) con el mundo físico (electrónica).
